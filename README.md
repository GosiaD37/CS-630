CS 630: Software Testing, Automation, and Quality Assurance

This repository contains selected coursework completed for CS 630: Software Testing and Quality Assurance at Southern New Hampshire University. The projects demonstrate my experience designing automated tests, evaluating valid and invalid inputs, testing API behavior, and documenting reproducible results.

This coursework strengthened my understanding that software quality requires more than confirming that a feature works under normal conditions. Effective testing must also examine invalid inputs, boundaries, API behavior, exceptions, security risks, and the clarity of the evidence produced. I learned to combine automated testing with careful documentation so that results are reliable, repeatable, and useful to a development team.
