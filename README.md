# CS 650: Software Development Lifecycle

This repository contains selected coursework completed for CS 650 as part of my Master of Science in Software Engineering program at Southern New Hampshire University. The projects and activities demonstrate my experience applying software engineering practices throughout the development lifecycle, including secure application development, automated testing, continuous integration, release planning, monitoring, and software quality.

Throughout this course, I worked with full-stack applications and practical development scenarios that required me to identify and resolve software issues, secure application routes and user data, implement automated testing, and integrate development workflows using Git and GitHub. The coursework also provided experience with continuous integration and deployment practices and reinforced the importance of incorporating testing and security throughout development rather than treating them as final steps.

This coursework strengthened my understanding of how development, testing, security, automation, and deployment work together to produce reliable software. I learned to approach software development from a lifecycle perspective, evaluate technical risks, troubleshoot application and pipeline issues, and document development and testing results so that they are reproducible and useful to other members of a development team.

## Key Skills Demonstrated

- Full-stack application development
- Software Development Life Cycle (SDLC)
- Secure API routes and authentication
- Automated software testing
- Continuous integration and deployment
- Git and GitHub version control
- Debugging and troubleshooting
- Software quality assurance
- Release planning and implementation
- Application monitoring and security
- Technical documentation
